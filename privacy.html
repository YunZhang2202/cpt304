Privacy Policy

This page explains what data the finance tracker stores, why it is stored, and how users can manage their choices.

Back to App

Last updated: May 2026

1. What we collect

The application stores transaction information entered by the user, including title, amount, category, and date. It also stores interface preferences such as theme, language, and cookie consent choice.

The application does not require account registration, passwords, payment card details, or server-side personal profiles.

2. Why we collect it

Transaction data is stored so the app can display the user's finance records after refreshing or reopening the page. Theme and language preferences are stored to improve usability. Cookie consent is stored so the banner does not repeatedly appear after a user makes a choice.

3. How we store and use data

This app stores data in the user's browser using localStorage. The data stays on the user's device and is not sent to an application database by this project.

Users can remove stored data by using the app controls where available or by clearing browser site data.

4. Cookie choices

On the first visit, the app shows a cookie preference banner. Users can choose Necessary Only, Reject, or Accept All. The current version only uses necessary local storage for app functionality and user preferences.

If non-essential analytics or third-party scripts are added in the future, they should only be enabled after the user gives consent.

5. Third parties

The app may be hosted on a cloud deployment platform. The hosting provider may process standard technical logs according to its own privacy policy. This project does not intentionally share user-entered finance records with third-party services.

6. Contact

For privacy questions, please contact the project team through the GitHub repository owner or the coursework group communication channel.

中文说明

隐私政策

1. 我们收集什么

本应用会在浏览器中保存用户输入的交易信息，包括标题、金额、类别和日期。同时也会保存界面偏好，例如主题、语言和 Cookie 选择。

本应用不需要注册账号、密码、银行卡信息，也不会创建服务器端个人资料。

2. 为什么收集

保存交易数据是为了让用户刷新或重新打开页面后仍能看到记录。保存主题和语言偏好是为了改善使用体验。保存 Cookie 选择是为了避免用户每次访问都重复看到提示横幅。

3. 如何存储和使用

本应用使用浏览器 localStorage 存储数据。数据保留在用户自己的浏览器中，本项目不会将这些财务记录发送到应用数据库。

用户可以通过应用功能或清除浏览器站点数据来删除本地保存的数据。

4. Cookie 选择

用户第一次访问时，应用会显示 Cookie 偏好横幅。用户可以选择“仅必要”“拒绝”或“全部接受”。当前版本只使用必要的本地存储来支持应用功能和用户偏好。

如果未来添加非必要分析工具或第三方脚本，应只在用户同意后启用。

5. 第三方

本应用可能部署在云平台上。托管平台可能会根据其自身隐私政策处理标准技术日志。本项目不会主动把用户输入的财务记录分享给第三方服务。

6. 联系方式

如有隐私相关问题，请通过 GitHub 仓库所有者或课程小组沟通渠道联系项目团队。
